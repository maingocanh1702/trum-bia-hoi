Run the autopilot flow for slice **{{SLUG}}** following `docs/autopilot-prompt-GENERIC.md` end to end.
This is generated by `/ap-new {{SLUG}}`; the manifest at
`docs/autopilot-manifests/{{SLUG}}.json` is the single source of truth.

Execute in order and HALT on the first breaker (§D), reporting it instead of pushing through:

1. **Pre-flight (§A).** Read the manifest + the backlog row + the spec it points to. `git fetch` and
   confirm `base_ref` exists. Confirm the prompt working set mirrors `scope`.

2. **Gate (§A.3.1) — before any branch/worktree mutation:**
   ```bash
   scripts/autopilot-scope-gate register --manifest docs/autopilot-manifests/{{SLUG}}.json
   ```
   On HALT (SCOPE_COLLISION / DEP_MISSING / INVARIANT_UNKNOWN) stop and report — do not work around it.

3. **Worktree (§A.4)** — only after PASS:
   ```bash
   git worktree add .autopilot/worktrees/{{SLUG}} feat/{{SLUG}} 2>/dev/null \
     || git worktree add .autopilot/worktrees/{{SLUG}} -b feat/{{SLUG}} "$(node -e 'console.log(require("./docs/autopilot-manifests/{{SLUG}}.json").base_ref)')"
   export DB_PATH=/tmp/ap-{{SLUG}}.db
   ```

4. **Build loop (§B).** Plan the smallest change; edit ONLY files in `scope`; if you need a shared
   domain file, stop and widen the manifest + re-gate. Verify fail-closed:
   `cd prototype && npm run build` (+ `npm run sim` / re-measure k for sim/economy slices).

5. **Review (§B.4).** Confirm `git diff --name-only <base_ref>...HEAD` ⊆ scope. Run codex per the
   manifest `codex_review` (`2x_clean` for P1, `1x_clean` for P2).

6. **STOP_AT_READY (§B.5).** When build + review are green:
   ```bash
   scripts/autopilot-scope-gate ready --manifest docs/autopilot-manifests/{{SLUG}}.json
   ```
   Then STOP. Report branch, files changed, verify + codex verdict, and merge policy. **Do NOT merge**
   — P1 is `manual_only` / `auto_merge:false`; the human owns the merge (§C) and runs `/ap-cleanup {{SLUG}}` after.
